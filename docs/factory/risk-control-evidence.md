# Risk, control, test, owner and evidence register

**Gate key:** G means Gate, a human approval checkpoint: G1 Scope, G2 Design, G3 Quality, G4 Release. Release authorises deployment of the exact reviewed version.

This is a target-factory acceptance register. **Owner names below are role assignments to establish, not confirmed people.** Existing local checks are identified; an unimplemented control remains a dependency. No target test is marked passed merely because it is listed.

## How to close a risk

Record the requirement and owner, the exact candidate/configuration tested, the test command or controlled procedure, expected/observed behavior, dated result and retained evidence hash/location. Failed or incomplete checks stay open. Link exceptions to the gate owner who accepted their scope; a worker recommendation cannot accept an exception.

Integration and migration acceptance must address business data correctness as well as security. A valid token, a green health check or a hash match does not establish correct transformation, adequate performance or safe recovery.
