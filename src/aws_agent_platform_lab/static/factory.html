Model proposal
Bedrock will supply worker responses. Schemas, source permissions and budgets will constrain what enters the workflow.

        
Independent execution
An isolated runner will execute the candidate and protected tests. A generated test report alone will never prove that the code works.

        
Human decision
Authorised people will inspect requirements, design, test evidence and the release target at their assigned gates.
